# alt-ime-linux

**左Altの単押しでIMEをOFF、右Altの単押しでIMEをONにする**、Linux向けキーボード変換ツールです。
Alt＋TabやAlt＋F4などのショートカットはそのまま使えます。

物理キーボードの入力を読み取り、Altの単押しを無変換／変換キーに置き換えて仮想キーボードから送信します。
IMEを直接操作しないため、入力方式名やATOK固有の設定は不要です。IME側で「無変換＝OFF、変換＝ON」を設定して使用します。

## 動作環境

- Linux、Python 3.9以降、`python3-evdev`
- systemdのユーザーサービスとudevが使えるデスクトップ環境
- 左右Altキーを持つキーボード1台
- 無変換／変換キーをON／OFFに割り当てられるIME

Kubuntu / KDE Plasma Wayland / Fcitx5 / ATOK / USキーボードでIME切替を確認しています。
IBusなどでも利用できる設計ですが、動作は未確認です。キー割り当ての可否や合成キーの受け取りは環境によります。

## インストール

### 1. パッケージを導入する

```bash
sudo apt install python3-evdev
```

### 2. IMEのキー設定を変更する

Fcitx5設定の「グローバルオプション」→「ホットキー」で、以下を設定します。
表示名はバージョンによって異なる場合があります。

| 設定 | 割り当てるキー |
|---|---|
| 入力メソッドを有効にする | 変換 (`Henkan`) |
| 入力メソッドを無効にする | 無変換 (`Muhenkan`) |

ONとOFFを分けて設定してください。「押すたびに切り替える」トグル設定ではありません。
ほかのIMEを使う場合も、同じ動作になるように設定します。

本ツールはIMEの設定を書き換えません。現在使っているIMEを有効／無効にするもので、複数のIMEから特定のものを選ぶ機能はありません。

### 3. インストーラーを実行する

このリポジトリのディレクトリで、デスクトップにログインしている**一般ユーザー**として実行します。

```bash
./install.sh
```

スクリプト全体をsudoで実行しないでください。必要な処理だけ内部でsudoを使います。
キーボードが1台なら自動選択し、候補が複数ある場合は番号で選択します。変更内容を確認すると、次の処理を行います。

- プログラム・設定・ユーザーサービス・アンインストーラーの配置
- uinputの有効化とアクセス権設定
- 必要な場合のみ `input` グループへのユーザー追加
- グラフィカルセッションでの自動起動登録

**有効にするにはコンピューターを再起動してください。** インストール直後にはサービスを開始しません。
初回の入力権限を確実に反映するため、ログアウト・ログインではなく再起動を案内しています。

キーボードを明示することもできます。

```bash
./install.sh --device /dev/input/by-path/実際のキーボード-event-kbd
```

`--yes` を付けると確認を省略できます。ただし、キーボードが複数ある場合は `--device` が必要です。
デバイス名には、再起動で変わる `/dev/input/eventN` ではなく、`/dev/input/by-id/` または `/dev/input/by-path/` の安定したパスを使います。

## 操作

| キー操作 | 動作 |
|---|---|
| 左Alt単押し | 無変換を送信（IME側の設定でOFF） |
| 右Alt単押し | 変換を送信（IME側の設定でON） |
| Shift＋左Alt単押し | Shift＋無変換を送信 |
| Shift＋右Alt単押し | Shift＋変換を送信 |
| Alt＋ほかのキー | 元のAltショートカットとして送信 |
| 同じAltを素早く2回 | 1回目は変換／無変換、2回目は元のAlt単押しを送信 |

単押しはAltを離した時点で処理します。ダブルタップは同じ側のAltの押下開始間隔が200ms未満の場合に判定し、左右の履歴は独立しています。
Shift以外のキーを挟むとダブルタップ判定を解除します。Ctrl・Super・通常キーを押しながらのAltや、左右Altの同時押しは通常の修飾キー操作として扱います。

Shiftを先に離した場合は、変換／無変換の送信中だけ左Shiftを補います。
Shift＋変換／無変換で何をするかはIME側で別途設定してください。

## 状態確認・停止

```bash
# 状態とログ
systemctl --user status alt-ime2.service
journalctl --user -u alt-ime2.service -b

# 一時停止
systemctl --user stop alt-ime2.service

# 起動
systemctl --user start alt-ime2.service

# 自動起動も解除して停止
systemctl --user disable --now alt-ime2.service
```

自動起動を戻す場合は `systemctl --user enable alt-ime2.service` を実行してください。

## 更新

更新後のリポジトリで `./install.sh` を再実行します。実行中のサービスは停止し、ファイルを更新します。
通常は案内どおりコンピューターを再起動してください。

既に入力権限が反映されていて、権限設定を変更しない更新の場合に限り、次の操作でも反映できます。

```bash
systemctl --user restart alt-ime2.service
```

## アンインストール

```bash
./uninstall.sh
```

リポジトリを削除・移動した後も、配置済みのアンインストーラーを使用できます。

```bash
~/.local/bin/alt-ime2-uninstall
```

サービスの停止・自動起動解除と、インストーラーが作成した未編集ファイルの削除を行います。
既存ファイル・編集済みファイル、IME設定、辞書は残します。

`input` グループ所属も既定では残します。このツールが追加した所属を戻す場合は、ほかの用途で使っていないことを確認して実行してください。

```bash
./uninstall.sh --remove-input-group
```

導入前から所属していた場合は削除しません。所属を削除した場合はコンピューターを再起動してください。
パッケージの削除やuinputモジュールのアンロードは行いません。

## 注意事項と制限

- **物理キーボードを占有します。** 試す前に、別キーボードかSSHから停止できるようにしてください。異常時は上記のサービス停止コマンドで復旧できます。
- `input` グループはキーボード入力全体を読み取れる強い権限です。共用端末への導入には注意してください。
- keyd・kanataなどのAlt変換設定とは併用しないでください。
- 対象は設定したキーボード1台です。抜き差し時の自動再探索は行いません。異常終了後はサービスが同じパスで再起動を試みます。
- ロック画面でのIME動作は保証しません。右AltがAltGrになる環境では、ダブルタップがメニュー操作にならない場合があります。
- キーボードLEDの逆方向同期は行いません。別の入力ノードから届く音量・特殊キーなどは変換対象外です。
- IME状態の共有、アプリ別のON／OFF、Shift併用の動作はIME側に依存します。

Ctrl+C・SIGTERM・切断・入力イベント欠落時には、送信中のキーを解放して物理デバイスの占有を解除します。

## 診断・手動実行

```bash
python3 alt_ime2.py --list-devices
python3 alt_ime2.py --device '/dev/input/by-path/実際のキーボード-event-kbd' --check
```

`--check` は物理キーボードの能力とuinputへのアクセス権だけを確認します。占有・仮想デバイス作成・IME操作は行いません。
切り替わらない場合は、サービスのログ、入力権限の反映、IMEの変換／無変換設定を確認してください。

手動で試す場合は既存サービスを停止し、すべてのキーを離してから起動します。

```bash
systemctl --user stop alt-ime2.service
sleep 1
python3 alt_ime2.py --device '/dev/input/by-path/実際のキーボード-event-kbd' --double-ms 200 --debug
```

終了はCtrl+Cです。手動プロセスはサービス停止の対象外です。操作不能なら別端末／SSHから `pkill -f '/alt_ime2.py'` で停止してください。

## 配置先と既存ファイルの保護

| 用途 | 配置先 |
|---|---|
| プログラム・セットアップ処理 | `~/.local/lib/alt-ime2/` |
| アンインストーラー | `~/.local/bin/alt-ime2-uninstall` |
| デバイス設定 | `~/.config/alt-ime2/environment` |
| ユーザーサービス | `~/.config/systemd/user/alt-ime2.service` |
| モジュール読込み設定 | `/etc/modules-load.d/alt-ime2.conf` |
| uinputアクセス権 | `/etc/udev/rules.d/70-alt-ime2-uinput.rules` |
| 管理記録 | `~/.local/state/alt-ime2/`、`/var/lib/alt-ime2/` |

無関係な既存ファイルや手動編集した管理対象ファイルは上書きしません。既存の同一内容のファイルは流用しますが、アンインストールでは削除しません。
管理記録は更新・削除時の判定に使います。入力内容は記録しません。複数ユーザーで導入した場合は、最後の利用者が削除するまで共通のシステム設定を残します。

## 開発用テスト

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile alt_ime2.py tools/setup.py
```

自動テストは実際のキーボードを占有せず、IMEも操作しません。キーイベント列、時間判定、異常時の後処理、インストール・更新・削除を検証します。
